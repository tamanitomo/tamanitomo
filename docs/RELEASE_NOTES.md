Tamanitomo 3.0.2 is about saying what is wrong while it can still be acted on.

Importing a workflow from a picture is how most people start, and it failed three separate ways, each blaming something other than itself. A render saved by ComfyUI carries a non-finite number on its nodes, which read back perfectly well and then made the reply impossible to encode — the error named no file and pointed nowhere. A graph built with a node pack was read by a reader that knew four stock node names, so it came back with no model, no LoRA, no numbers and no wired prompt, and was called incomplete for being unfamiliar; a pack's sampler still calls its inputs `steps` and `cfg`, and that is what is read now. And a link copied from the civitai.red mirror died at the fetch, because that host refuses an ordinary client, with an error that blamed the link.

The larger change is that an import now says what your ComfyUI is missing. A workflow naming a node pack you do not have, or a model twice the size of your graphics card, used to fail much later with an out-of-memory error thrown from somewhere deep inside ComfyUI — which reads as "this is broken" rather than "install this" or "this will not fit on this card". The import names the missing nodes, names the missing weights, reads the card's VRAM, and where a model will not fit says so plainly and explains that the same weights usually exist quantised, at a size that will. It does not offer that advice to someone who already has a quantisation.

Elsewhere: saving a preference no longer reports that background jobs could not be updated when they were updated and something unrelated was merely flagged; a background worker survives a refused retry; a reasoning model is given room to answer after it finishes thinking; Hermes is found in a checkout made by `uv`; a plan retires the items whose time has quietly gone by, and carries the reasons a day changed into what she is thinking with; and updates stop keeping a full copy of the application forever.

### Install

Download **tamanitomo-release.zip** below, extract it into its own application folder, and run the Tamanitomo launcher. Keep your Hermes home and vault outside that folder. The automatically generated GitHub source archives are for development; use the attached release ZIP for in-app updates.
