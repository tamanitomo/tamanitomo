Tamanitomo 2.3.6 brings photo fixes, moment variations, and natural daily routine transitions.

Photo fixes resolve issues where prompt styling and clothing constraints conflicted with natural daily routines. When capturing moments like bathing or personal downtime, the companion's wardrobe state is accurately honored without forcing contradictory outerwear.

Moments now support multi-provider variations. In the photo viewer, you can retry rendering an existing moment using any of your configured image providers while strictly preserving the companion's recorded scene, activity, and identity. A variation switcher in the lightbox lets you flip between versions and choose "Use this photo for this moment" to set your preferred version for the timeline and gallery cards. The photo details pane also inspects both the prose and structured prompts used during capture.

Routine transitions and clothing hygiene have been refined. Showers and personal routines are paced naturally (with showers capped at 40 minutes). Removed garments transition cleanly to laundry care rather than staying worn, sleepwear is kept to bedtime and morning relaxation at home, and companions change into daytime clothes before heading out.

### Install

Download **tamanitomo-release.zip** below, extract it into its own application folder, and run the Tamanitomo launcher. Keep your Hermes home and vault outside that folder. The automatically generated GitHub source archives are for development; use the attached release ZIP for in-app updates.
